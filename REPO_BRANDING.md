# Repository Branding Guide

This file contains the recommended public-facing branding for the Poseidon repository.

## Recommended GitHub repository name

**Poseidon**

## Recommended short description

**Advanced ADB toolkit for Android diagnostics, automation, monitoring, and OCR-driven UI workflows.**

## Alternative short descriptions

1. **Professional ADB-based Android toolkit with monitoring, automation, and OCR/UI vision workflows.**
2. **Modular Android device operations toolkit powered by ADB, monitoring, and OCR-assisted automation.**
3. **High-end Android device toolkit for diagnostics, terminal workflows, monitoring, and UI text automation.**

## Recommended homepage text / About copy

Poseidon is a modular Android operations toolkit built around ADB. It combines interactive terminal workflows, headless CLI automation, device monitoring, exportable metrics, and OCR-powered UI assistance for practical diagnostics and controlled automation.
