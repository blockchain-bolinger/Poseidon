# Roadmap

- Module als Plugins ausgelagert: phonesploit_pro, androidhack_backdoor, androrat
- Plugin-Discovery automatisch verifizieren
- Tests für neue Module ausbauen

- Batch-Support für neue Module

- Lokale CVE-Regeln auslagern und versionieren

## Langfristig
- Erweiterbare Rule-Engine für Module
- Offline-Skill-Export für Geräteprofile
- Plattformübergreifende Basis: iOS-Features prüfen
